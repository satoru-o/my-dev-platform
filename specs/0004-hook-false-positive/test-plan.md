## テストの順序（1件ずつ進める）
最初に、今通っているもの（退行の網）を足す。修正中に壊れたら、すぐ分かる。そのあと、Red になるものを足す。

1. 退行の網: `p='CLAUDE.md'` のあと `open(p,'w')` → 拒否（今も拒否。通っていても Red にはならない）
2. 退行の網: `bash <<'EOF'` と `cat <<'EOF' | bash` の本文 → 拒否
3. 退行の網: `p='specs/a.md'` のあと `open(p,'w')` → 通る
4. **Red**: python の heredoc（今回の事例）→ 通る
5. **Red**: `cat > specs/x.md <<'EOF'`、本文の行頭が `touch .claude/x` → 通る
6. S-02: 書き込みが2つ（1つが保護対象）→ 拒否
7. V-03: 日本語・絵文字の本文
8. （Round 2 の回答後）Q4: 引用符なしの heredoc の `$(…)`、Q5: heredoc のあとの行、Q6: 1MB の入力

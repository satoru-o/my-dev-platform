## テストの順序（1件ずつ進める）
1. AC-1: 初回追加（c1 に p1 x 2 → 201、カート全体が返る）
2. AC-1: 続けて p2 x 1（追加順に並ぶ）
3. AC-2: 同じ商品の加算（p1 x 2 + 3 → 5）
4. S-01: 存在しない商品 → 404、エラー形式
5. V-02: 0 / -1 / 100 → 422、99 → 201
6. V-02: 合算で99超 → 422（カートは変わらない）
7. V-03 / V-01: 型違い・欠落 → 422
8. X-04: エラー本文に内部情報が無い

## 迷いどころ（人間に見てほしい所）
- ⚠️ V-02 の境界値は、あなたの例ではなく質問の回答（1〜99）から取っています。境界の具体例を、あなたの言葉で1〜2個ください（例: 「99個まではOK」）。
- ⚠️ 合算超過（50+50）の期待値が422でよいか。よければ「OK」だけで進みます。
- ⚠️ X-04 の「内部情報が無い」の確認方法。提案: 本文に `Traceback`、`.py`、`pydantic` の文字列が含まれないことをassertする。
